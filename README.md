# Employee Leave Management System

A comprehensive cloud-hosted HR system for managing employee leave applications, approvals, and analytics. The system features role-based access control, real-time leave balance tracking, multi-level approval workflows, and detailed analytics.

## 🚀 Features

### Core Features
- Employee profile and role management (Employee, Manager, Admin)
- Leave application and approval workflow
- Real-time leave balance tracking
- Email notifications for approvals/rejections

### Intermediate Features
- Multiple leave types (Sick, Casual, Paid, Maternity, Paternity)
- Leave history per employee
- Holiday calendar integration
- Automatic leave balance updates

### Advanced Features
- Multi-level approval workflow
- Policy-based leave rules
- Department-wise analytics and reports
- Audit logs for all actions
- Calendar visualization

## 🛠️ Technology Stack

### Backend
- Java 11
- Spring Boot 2.7.14
- Spring Security with JWT
- Spring Data JPA
- PostgreSQL
- Maven

### Frontend
- React 18
- React Router v6
- Bootstrap 5
- Formik & Yup for forms
- Chart.js for analytics
- Axios for API calls
- React DatePicker

### DevOps
- Docker & Docker Compose
- Render (Cloud Deployment)
- GitHub Actions (CI/CD)

## 📋 Prerequisites

- Java 11 or higher
